# Templates

Each file here is one row an `add` command writes, laid out as its file: the same blocks, every field in schema order. Copy the file, fill it, and pass the copy with `--from`:

```
cp templates/asset.json ionqx.json
pnpm rwa add asset --from ionqx.json --dry-run
pnpm rwa add asset --from ionqx.json
```

The command runs the same checks as the flag form on a copy of the registry. On an error it prints `file: message`, writes nothing and exits 1; `--dry-run` prints the file it would write.

## Filling one

- Replace every example value. A field that holds `null` is optional, and a list you do not need stays `[]`.
- `slug`, `legacyId` and `legacyPid` are optional where the template has them null. Left null, the command assigns the next free one: the slug from the name, label or canonical market id, and an asset's legacy id one above the highest; a market or organization then gets none. Filled, the command keeps the value, and the unique-key check refuses one another row holds, naming it.
- A vocabulary field takes a slug from `registry/reference/vocabularies/`. A value that is not there is refused, and the message names the nearest one.
- A row a field names must exist first: the platform before its assets, the underlying before an asset or market that tracks it, the venue before its markets, and the organization before a role or venue names it.
- An identifier holds its `scheme` (isin, figi or lei) and its `value`.
- A key the schema does not know is refused.

## The files

| Template                | Command            | Writes                                       | Notes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ----------------------- | ------------------ | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `asset.json`            | `add asset`        | `assets/<platform>/<slug>.json`              | `platform` names the folder and is left out of the file. `category` lists the shelves it sits under, slugs of the category vocabulary, first the main one. A deployment without `deployedAt` is dated from the chain; under `--no-discover` it stays undated and `validate` warns until the date is set. A deployment with `address: null` names a chain with no known contract: the chain is listed, nothing is read there and no date is asked; only `--from` gives one, since `--deployment` takes `<chain>:<address>`. The deployment marked `primary` names the primary chain. `roles` needs one issuer, which the published issuer name and its `protocolIds` come from; the other roles, the label and the event are examples. `about.links` holds the asset's own `website` only: its social accounts and referral links are its platform's, and its issuer's registry text is the issuer organization's `about.registryInfo`. |
| `platform.json`         | `add platform`     | `assets/<slug>/platform.json`                | An asset folder needs it before its first asset. Its `about.links` holds the social accounts and referral links of its assets.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `organization.json`     | `add organization` | `reference/organizations/<kind>/<slug>.json` | `kind` names the folder. A platform goes through `platform.json`, a venue operator through `add venue`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `venue.json`            | `add venue`        | `perps/<slug>/venue.json`                    | Its organization must exist, or `operator` is filled with its `slug`, `name` and `links` and written beside the venue as `perps/<slug>/organization.json` of kind venue-operator. `published` stays false until the server's adapter is merged. The website and name the app shows for the venue are its organization's.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `market.json`           | `add market`       | `perps/<venue>/<lowercase symbol>.json`      | `venue` names the folder. Fill `tracks.underlying` or `tracks.asset`, not both. Its `roles` hold an oracle role only where the market's oracle differs from its venue's oracle roles. Leave `events` empty, and the command asks the venue for the listing date; under `--no-discover` it asks none and the market gets no listing event. A market's logo is its underlying's `logo`, and its referral link is the venue organization's `about.links.refLinks`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `underlying.json`       | `add underlying`   | `reference/underlyings/<class>/<slug>.json`  | The folder is the class the asset group of `exposure` names, so the file holds no `class`; `exposure` is the asset group it is. `logo` is the logo the markets that track it show.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `vocabulary-value.json` | `add value`        | `reference/vocabularies/<vocabulary>.json`   | Added in slug order.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
